# 🛡️ ServerVault

> Automated Server Backup & Disaster Recovery Bot for Discord.

ServerVault provides disaster recovery, member role preservation, and automated structural backups for Discord communities of all sizes (up to 100,000+ members).

---

## ✨ Features
* **Automated & Manual Backups:** Complete snapshots of channels, roles, categories, and permissions.
* **Member Role Preservation:** Protects against rogue administrator raids by saving member role assignments.
* **Asset Archival:** Backs up custom emojis, stickers, and soundboard audio.
* **Non-Destructive Restoration:** Recover corrupted or deleted channels without wiping your entire server.

---

## 📋 Commands
* `/backup` — Create a manual server backup snapshot.
* `/backups` — View available backup history with file sizes.
* `/dashboard` — Visual server protection center and backup status.
* `/restorepreview` — Preview missing roles and channels before executing a restore.
* `/restore` — Safely restore server structure.
* `/subscribe` — View subscription tiers (Free, Pro, Business, Enterprise).

---

## 🔒 Privacy & Security
* ServerVault only reads server structures to perform authorized administrative backups.
* Private Direct Messages (DMs) and voice audio are never recorded or stored.
